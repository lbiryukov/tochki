# Точки

Игра в точки на листе в клетку 39×32: вдвоём на одном телефоне или по ссылке, каждый со своего. Ничего не нужно устанавливать.

**Играть:** https://lbiryukov.github.io/tochki/

- Окружите точки соперника замкнутой цепочкой, и они ваши. Очки дают только за захваченные точки.
- Настройки новой партии: дополнительный ход за окружение и время на ход.
- В конце партии видно, сколько каждый в среднем думал над ходом.

## Разработка

```
npm install
npm test           # движок и правила базы
npm run build      # собрать index.html из src/
npm run mock       # локальная проверка с подменной базой: http://localhost:8787/
```

Исходники лежат в `src/`, правила базы в `firebase/`. `index.html` в корне собирается скриптом, руками его не правят. Подробности устройства и выкладки описаны в [CLAUDE.md](CLAUDE.md).
